## Overview

This directory contains the server-side implementation surface for the social-mcp project's Model Context Protocol (MCP) components. At the top level there are no source files; the substantive code is organized under the src/ subdirectory. The primary artifact in this area is a single TypeScript module (server.ts) that wires together pieces of the MCP server stack and exposes utility functions consumed by server code.

The src/ subdirectory houses the core server wiring and auxiliary utilities. server.ts is declared to integrate the server stack and provide a small set of utilities for consumption by the rest of the server application. Together, the files in this directory define how MCP server components are composed and how other parts of the system should interface with MCP functionality. This directory therefore plays the role of the MCP server integration layer within the larger social-mcp codebase, centralizing the server composition and exported helpers used by higher-level services.


### File Organization

There are no files at the directory root; all implementation lives under src/. The src/ subdirectory groups the MCP server wiring and utilities into a single module (server.ts) so that integration code and helpers are colocated and easier to locate.
