## Overview

This module implements local, deterministic review gates for release and delivery evidence. It provides small, focused utility functions that evaluate supplied inputs without performing side effects: classification of aggregate delivery, review of release evidence, and selection or preservation of current factual evidence. The module explicitly avoids connecting to external services or performing actions such as sending email, modifying records, or publishing releases, and is intended to be used only with inputs provided by an authorized external source.

Functions in this file are oriented toward decision-making and evidence handling: they classify delivery outcomes without inferring root causes, validate release evidence as a reviewer (where a pass is informational rather than an instruction to deploy), and resolve conflicting facts by choosing an authoritative current evidence item or preserving a conflict state. The implementation emphasizes read-only evaluation of provided data and deterministic behavior in its outputs.
