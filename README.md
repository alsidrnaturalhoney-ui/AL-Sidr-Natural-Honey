## Guardrails

- Inspect before changing.
- Reuse existing systems before creating new ones.
- Never expose secrets or customer PII.
- Never make destructive production changes without explicit approval.
- Never fabricate product claims, awards, certifications, origins, prices, reviews or metrics.
- Distinguish verified facts, assumptions, recommendations and experiments.
- Preserve bilingual English/Arabic quality and premium heritage positioning.
