## Phase 1 — Source-of-Truth Stabilization

- [ ] Keep Notion, Shopify and GitHub synchronized.

- [ ] Connect content performance to Shopify revenue where data permits.

## Phase 4 — Retention & CRM

- [ ] Validate customer lifecycle segments.
- [ ] Build evidence-based 45/52/60-day reorder journeys.
- [ ] Connect email/WhatsApp automation through approved systems.

## Phase 5 — Operational Infrastructure

- [ ] Expose/authorize Airtable before migrating operational data.
- [ ] Expose/authorize Supabase before deploying application/database infrastructure.
- [ ] Re-authorize Manus before autonomous execution.
- [ ] Establish governed webhook/orchestrator architecture.
- [ ] Deploy validation ledger only after database ownership is confirmed.

## Phase 6 — Governed AI / MCP Apps

- [ ] Stabilize source-of-truth boundaries.
- [ ] Define explicit MCP read/write scopes.
- [ ] Add audit logging and validation gates.
- [ ] Test one low-risk workflow before scaling.
- [ ] Introduce autonomous execution only with reversible actions and human approval for material changes.

## Phase 7 — Scale

- [ ] Expand retail intelligence and distribution tracking.
- [ ] Automate executive reporting.
- [ ] Build competitive intelligence loops.
- [ ] Optimize content-to-commerce attribution.
- [ ] Continuously review security, cost, performance and data quality.

## Priority Rule

**Revenue impact + risk reduction + source-of-truth integrity > volume of tasks completed.**
