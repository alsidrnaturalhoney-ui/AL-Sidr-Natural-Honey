# AL SIDR Canonical Grok Skills Pack

Eleven Grok-compatible skills from the AL SIDR OS Skill Register
(Notion, 20 August 2026) plus Support Copilot.

Each folder is a skill: upload the folder, the `SKILL.md`, or the zip to Grok
Skills. Slash commands match the folder name, for example `/al-sidr-brand-guardian`.

## Install

1. Grok → Skills → upload this zip (or each `SKILL.md`).
2. Or copy folders into `.grok/skills/` in a repo.
3. Call with `/skill-name` or let Grok match the description.

Do not create parallel operating systems. Canonical registry lives in Notion.
