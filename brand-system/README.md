# Al Sidr Natural Honey Brand Operating System

This package turns the available Al Sidr conversation context into a reusable foundation for brand, content, customer experience, commerce, design, and agent workflows.

## Package map

| Folder | Purpose |
|---|---|
| `knowledge-base/` | Canonical brand facts, voice, customer framework, channels, claims boundaries, and audience definitions. |
| `skills/` | Reserved space for future project-specific reference skills. The installable skills are stored under `/home/ubuntu/skills/`. |
| `design-system/` | CSS tokens and a machine-readable brand manifest. |
| `templates/` | Content briefs and customer-support structures. |
| `agents/` | Specialist agent roster, triggers, outputs, handoffs, and human approval gates. |
| `ideas/` | Prioritized growth and innovation hypotheses. |
| `code/` | Implementation-ready HTML/CSS example using the brand tokens. |

## Installable skills

The following validated skills were created in `/home/ubuntu/skills/`:

| Skill | Use |
|---|---|
| `al-sidr-brand-orchestrator` | Cross-functional brand, content, commerce, and compliance orchestration. |
| `al-sidr-bilingual-copy` | Natural premium English-Arabic copy for UAE/GCC audiences. |
| `al-sidr-support-copilot` | WhatsApp, DM, email, FAQ, and escalation replies. |
| `al-sidr-social-growth-planner` | Platform-native organic content and growth experiments. |

## Operating principle

Every output should educate the customer, personalize the recommendation or message, and give a clear next direction to a verified Al Sidr channel. The standard pipeline is **Input → Processing → Output → Optimization → Human Review**.

## Important verification note

This system was assembled from the available conversation history. Before public publication, confirm live prices, stock, delivery promises, retailer availability, award and certification wording, social handles, locations, and any regulated product claims.
