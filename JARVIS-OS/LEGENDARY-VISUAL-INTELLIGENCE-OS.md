# AL SIDR LEGENDARY VISUAL INTELLIGENCE OS

## Canonical Evolution Directive — 2026-08-26

The AL SIDR OS is a visual-first, symbol-first, motion-aware, continuously evolving intelligence ecosystem.

### Generate
- Skills: discover gaps, design, validate, version, register.
- Agents: mission, permissions, tools, knowledge, validation, escalation.
- Prompts/instructions: versioned, testable, reusable, governed.
- Knowledge: source, authority, freshness, confidence, provenance.
- Brand voice: heritage-led, premium, precise, warm, modern, trustworthy; never invent claims.
- Visual system: luxury gold/cream/charcoal foundation plus functional status colors, accessibility and contrast.
- Connectors: capability, permissions, auth state, approval gate, audit trail.
- MCP/API integrations: design, secure, test, document, then deploy.

### Visual-first law
Prefer icons, symbols, diagrams, status lights, honeycomb nodes, holographic layers, motion graphics, particles, energy trails, animated workflows and visual relationships over unnecessary text. Detailed text remains available on demand for auditability.

### Canonical architecture
- Shopify = commerce truth
- Notion = knowledge/governance truth
- GitHub = engineering/source truth
- Supabase = application/backend layer
- Chronos for Codex = execution/scheduling capability when connected
- Shopify App Builder = Shopify app capability layer

### Secret law
Never expose, paste, store in prompts, commit to Git, or place API keys/secrets in Notion. Use provider-secure authentication and environment/secret references.

### Evolution loop
OBSERVE → LEARN → DEDUPLICATE → DESIGN → BUILD → VALIDATE → REGISTER → CONNECT → MEASURE → IMPROVE

### Anti-duplication law
Reuse and upgrade existing AL SIDR capabilities before creating parallel agents, dashboards, prompts, databases, registries or orchestration systems.
